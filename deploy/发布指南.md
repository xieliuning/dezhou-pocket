# 发布指南 · 让朋友在微信里点开就玩

> 适用版本：1.8（含同桌联机）　更新时间：2026-10-24

## 结论先行

| 方案 | 花费 | 上线耗时 | 国内微信访问 | 支持联机 |
| --- | --- | --- | --- | --- |
| **A. Zeabur（推荐）** | 免费起步 | 5–10 分钟 | 好（香港节点） | ✅ |
| B. 腾讯云轻量服务器·香港 | 约 ¥30/月 | 30 分钟 | 最稳 | ✅ |
| C. Netlify / Vercel 等纯静态托管 | 免费 | 10 分钟 | 不稳定 | ❌ 仅单机 |

**推荐 A**：免费、免备案、自动 HTTPS，香港节点国内微信可直连。联机功能需要 Node 服务，所以不再是"传个静态文件夹"就完事，但依然只需几步。

## 0. 先弄清楚的三件事

1. **两种玩法两种部署**：
   - 单机（`play.html`）：纯静态，任何托管都能放；
   - 同桌联机（`room.html`）：需要跑 `node server/server.js`（零 npm 依赖，Node ≥16 即可），房间、牌局、底牌全在这台服务器上。
2. **为什么不是"微信小游戏"**：游戏类目需要企业/个体工商户主体 + 软件著作权，棋牌类还涉及版号，个人发不了。H5 链接发到微信点开即玩，不需要任何审核。
3. **备案**：香港/境外服务器**不需要 ICP 备案**；大陆机房 + 绑域名才需要（2–4 周）。

## 方案 A：Zeabur 免费部署（推荐）

Zeabur 会按项目根目录的 `package.json` 识别为 Node 服务，执行 `npm start`（即 `node server/server.js`），并注入 `PORT` 环境变量，无需任何配置。

1. 打开 [zeabur.com](https://zeabur.com)，用 GitHub 账号注册/登录。
2. 方式一（CLI，推荐）：项目根目录执行
   ```bash
   npx zeabur@latest deploy
   ```
   按提示选择项目与区域 **Hong Kong**。方式二：把整个项目文件夹推到 GitHub 仓库后，在 Zeabur 控制台 Add Service → Git 导入。
3. 服务页 → **Networking** → **Generate Domain**，得到 `xxxx.zeabur.app`（自动 HTTPS）。
4. 微信里发两个链接给朋友：
   - 单机练习桌：`https://xxxx.zeabur.app/play.html`
   - **联机开黑**：`https://xxxx.zeabur.app/room.html` —— 建房后把带 `?room=房间号`（4 位数字）的链接发到群里，朋友点开 → 填昵称 → 默认上桌，九个座位随便换，也可勾选围观。

> 免费档跑一个这样的房间服务器绰绰有余。若以后访问量变大或想要更高保障，再升级付费或换方案 B。

## 方案 B：腾讯云轻量服务器·香港（最稳）

1. 购买**轻量应用服务器**，地域**中国香港**，镜像 Ubuntu 22.04（新用户常有约 ¥99/年 活动机）。无需备案。
2. 上传整个项目并安装 Node：
   ```bash
   # 本机
   scp -r dezhou-v2 root@<服务器IP>:/opt/dezhou
   # 服务器上
   apt update && apt install -y nodejs npm caddy
   ```
3. 用 systemd 常驻：
   ```bash
   tee /etc/systemd/system/poker.service <<'EOF'
   [Unit]
   Description=Yehang Poker server
   After=network.target
   [Service]
   WorkingDirectory=/opt/dezhou
   ExecStart=/usr/bin/node server/server.js
   Environment=PORT=8080
   Restart=always
   [Install]
   WantedBy=multi-user.target
   EOF
   systemctl enable --now poker
   ```
4. Caddy 反代（顺带自动 HTTPS，需要一个 ~¥50/年 的域名解析到服务器 IP）：
   ```
   你的域名 {
     reverse_proxy 127.0.0.1:8080
   }
   ```
   没有域名也可以先用 IP：`caddy` 配置首行写 `:80`，微信里访问 `http://<IP>/room.html`。
5. 腾讯云控制台 → 防火墙 → 放行 80（和 443）端口。

## 方案 C：纯静态托管（只够单机）

Netlify / Vercel / Cloudflare Pages 拖传 `dist/` 即可，但**没有后端，`room.html` 联不了机**（大厅会一直连不上服务器）。国内访问也不稳定，只建议当单机版的备用。

## 部署后 30 秒自检清单

- [ ] 微信打开 `/room.html`：能建房，房间号出现
- [ ] 两个手机分别进房、开局、各拿各的底牌、轮流行动；点空位能换座
- [ ] 断网重进（或杀掉微信重开链接）能回到座位
- [ ] 单机页 `/play.html` 正常
- [ ] 分享出去的卡片：标题 + 德州扑克缩略图正常

## 微信传播注意事项

- 定位是**免费娱乐、无真钱、无转账、无抽奖**，正常分享不会被封；文案避免「赌、赢钱、提现」等字眼。
- 链接出现「非微信官方网页」提示时点**继续访问**即可；万一域名被彻底封禁，换域名重新发布（方案 B 自有域名最抗封）。
- 不要把 H5 冒充"微信小游戏"提交审核——棋牌类目个人主体不可行，链接分享不需要审核。

## 联机服务的运行边界

- 房间数据在**内存**里：服务器重启后所有房间消失（进行中的牌局作废），这是刻意保持的简单性，朋友局足够用。
- 每手 60 秒思考时间，超时自动过牌/弃牌；掉线座位保留 5 分钟，之后自动请离。
- 单个房间 2–9 人；开局后进来的朋友只能观战，下一局开始前入座即可。
