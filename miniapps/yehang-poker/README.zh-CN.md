# 夜航俱乐部 · 德州扑克

一个装在 MiniMax Code 里的德州扑克牌桌，一个窗口四个标签：

| 标签 | 作用 |
| --- | --- |
| **联机牌桌** | 连公网牌局服务器，进房上桌，把邀请链接发给朋友 |
| **AI 陪练** | 九人桌，八位 AI 对手，沿用同一套二十套可切换的牌桌风格 |
| **桌主控制台** | 房间号、在座与围观人数、盲注、席位名单、邀请链接 |
| **服务器** | 填写牌局服务器地址并做连通性自检 |

Mini App **不跑牌局**。它只托管牌桌页面、记住服务器地址、把 `/ws` 转发给那台服务器；
发牌、下注、结算全在服务器上完成，所以房间状态存在服务器那边，而不是 Mini App 里。

## 和朋友一起玩

1. 先把牌局服务器部署出去（零 npm 依赖，Node ≥ 16）：

   ```bash
   npm start        # = node server/server.js，监听 0.0.0.0:8080
   ```

   服务器项目自带 `render.yaml`（Render Blueprint）、Hugging Face Spaces 的 `Dockerfile`，以及一份
   部署指南。任何支持 HTTPS 并转发 WebSocket 的托管都行——Render、Railway、Zeabur 或自己的 VPS。

2. 打开「服务器」标签，填入公网地址（例如 `https://your-poker.onrender.com`），点
   **保存并应用**，等到提示「牌局服务器可达」。

3. 打开「联机牌桌」标签建房，复制邀请链接。链接指向公网服务器地址，朋友点开就能上桌。

地址可以不带协议：裸 IP 和 `localhost` 按 `http://` 处理，域名按 `https://` 处理；
写 `ws://` / `wss://` 也会自动换算。

## 数据访问与存储

- 这个 Mini App 只访问**你自己配置的那台牌局服务器**，通过 HTTPS（页面与 WebSocket）。
- 服务器地址保存在 Mini App 自己的运行时数据目录里，不写进页面，也不会随房间分享出去，更不会
  交给 Agent。
- 点「测试连接」时会对 `<地址>/room.html` 做一次只读探测，确认返回的确实是夜航牌桌页面。
- 无账号、无统计、无遥测、不涉真钱。

## 测试环境

- MiniMax Code 3.1.2，Windows 11
- 建房、上座、刷新后自动回座、与第二个客户端完整打完一手到摊牌
- 在应用内风格面板切换全部二十套风格，联机桌与单机桌同步生效
- 服务器地址配置、连通性自检、保存并应用
