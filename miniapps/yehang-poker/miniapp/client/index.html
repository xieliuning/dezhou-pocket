牌局服务器

Mini App 本身不跑牌局，它连接你部署好的公网服务器，所有发牌与结算都在那边完成。

服务器地址

填 server/server.js 部署后的公网地址。

支持 http:// 与 https://；没写协议时，裸 IP 与 localhost 按 http 处理，域名按 https 处理。地址保存在本机，不会随房间分享出去。

怎么把服务器部署到公网

项目自带零依赖 Node 服务，部署一次就能一直用。

  1. 今晚就想和朋友玩（免绑卡、国内能开）：在这台电脑上跑 node tools/tunnel.js。它会自动起牌局服务器，再拉一条 Cloudflare 官方隧道，给你一个 https://xxx.trycloudflare.com 地址——朋友点开就能进，不用输密码。把地址填到下面的「牌局服务器地址」，或者直接把这个链接发群里。代价：电脑要一直开着，隧道重启后地址会变。
  2. 想 24 小时都在线（免绑卡）：注册 dash.cloudflare.com 账号（免费档不要绑卡）→ 本机跑 npx wrangler login 浏览器授权 → 再跑 npx wrangler deploy → 得到 https://yehang-poker.xxx.workers.dev。前端和牌局服务器同源，房间状态落盘、电脑关掉也能继续玩。注意：workers.dev 在中国大陆打不开（被 DNS/SNI 拦截），国内要长期用请再绑一个自己的域名。
  3. 最省事（要绑卡）：在 render.com 用 GitHub 登录 → New → Blueprint → 选本仓库 → Apply。仓库自带 render.yaml，零依赖不用构建，平台自动跑 npm start。
  4. 或者在 zeabur.com 导入仓库，区域选 Hong Kong，同样自动执行 npm start。
  5. 在服务页生成域名（https://xxx.onrender.com / https://xxx.zeabur.app / https://xxx.workers.dev），把地址填到这里保存，朋友就能进房了。

Render 免费实例空闲 15 分钟会休眠（牌局开着时客户端心跳会让它保持在线），房间数据在内存里，休眠后房间清空。长期玩建议用 Zeabur / Railway、Cloudflare Workers 或自己的服务器。

不想注册任何平台？直接 node tools/tunnel.js 就行，牌局服务器和隧道它都帮你起。

想在同一台电脑上先试手，也可以填 http://127.0.0.1:8080，前提是已经运行了 node server/server.js。
